ProfLens Privacy Policy

Last updated: May 12, 2026

Overview

ProfLens is a Chrome extension that displays Rate My Professors ratings on the Texas Tech University Schedule Builder. We are committed to protecting your privacy.

Data Collection

ProfLens does not collect, store, or transmit any personal information. Specifically, we do not collect:

  • Names, email addresses, or any personally identifiable information
  • Browsing history or web activity
  • Authentication credentials or login information
  • Location data
  • Financial information

How the Extension Works

When you visit the TTU Schedule Builder, the extension reads professor names displayed on the page and sends those names to our backend API to retrieve publicly available ratings from Rate My Professors. No user data is sent — only professor names that are already visible on the page.

Local Storage

The extension stores a single preference locally on your device (whether ratings are enabled or disabled). This data never leaves your browser.

Third-Party Services

The extension communicates with our API server to fetch professor ratings. The API server queries Rate My Professors' publicly available data. No user information is shared with any third party.

Data Sharing

We do not sell, trade, or transfer any data to third parties. We do not use analytics, tracking, or advertising services.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected on this page with an updated date.

Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository.
